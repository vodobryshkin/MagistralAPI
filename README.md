# API сайта "Магистраль"
## Swagger
Для просмотра сгенерированной swagger'ом документации нужно после запуска программы перейти по ссылке: http://localhost:8080/swagger-ui/index.html#/

## Хранилище заказов
Для просмотра документов нужно:
1. Запустить бэкенд
2. Перейти по ссылке http://localhost:9001/login
3. Ввести логин и пароль (взять из .env-файла в корне проекта)
4. Можно смотреть заказы. Заказы хранятся по дням, при этом хранилище имеет следующую структуру: `orders/<год>/<месяц>/<день>`
